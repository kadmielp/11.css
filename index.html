11.css

A design system for building faithful recreations of Windows 11 UIs. v0.1.0

11.css takes semantic HTML and makes it look like Windows 11. It is the next member of the 98.css, XP.css and 7.css family and uses the same markup, so swapping the stylesheet restyles an existing 98/XP/7 page without changing its HTML.

It ships no JavaScript, so it works with any frontend framework. Accessibility comes from semantic HTML: buttons are <button>, inputs have labels, tabs use role="tab", and title-bar buttons are named with aria-label.

Hello, world!

</div>

Window

A window is a div.window with a .title-bar and a .window-body. Windows 11 title bars share the window colour; caption buttons sit flush in the top-right corner and Close turns red on hover.

Title bar

Caption buttons are named by aria-label: Minimize, Maximize, Restore, Help and Close. Add .inactive to the title bar for a window without focus.

Window body and status bar

.window-body adds spacing around the content; use .window-body.has-space for padding instead of margin. A .status-bar of .status-bar-field elements goes at the bottom.

Acrylic

.window.acrylic blurs whatever is behind the window with backdrop-filter, an approximation of Windows 11 acrylic. Without it, windows use a solid Mica-like background.

Acrylic window

The background shows through, blurred.

Show code 
<div style="padding: 24px; border-radius: 8px; background: linear-gradient(135deg, #0078d4, #8e44ad 55%, #f39c12)">
  <div class="window acrylic" style="width: 300px">
    <div class="title-bar">
      <div class="title-bar-text">Acrylic window</div>
      <div class="title-bar-controls">
        <button aria-label="Close"></button>
      </div>
    </div>
    <div class="window-body">
      <p>The background shows through, blurred.</p>
    </div>
  </div>
</div>

Button

A standard <button>. Add class="default" for the accent (primary) button. .active and .focused show the pressed and keyboard-focus states without interaction.

Show code 
<div class="field-row">
  <button>Click me</button>
  <button class="default">Save</button>
  <button disabled>Disabled</button>
  <button class="default" disabled>Disabled</button>
</div>
<div class="field-row">
  <button class="active">Pressed</button>
  <button class="focused">Focused</button>
</div>

Tabs

A menu[role=tablist] of button[role=tab] followed by a [role=tabpanel]. Mark the current tab with aria-selected="true". By default tabs look like the Windows 11 Settings selector; add .tabview to the menu for browser-style tabs.

The tab content.

Show code 
<menu role="tablist" aria-label="Sample tabs">
  <button role="tab" aria-selected="true" aria-controls="tab-a">Desktop</button>
  <button role="tab" aria-controls="tab-b">My computer</button>
  <button role="tab" aria-controls="tab-c">Control panel</button>
</menu>
<article role="tabpanel" id="tab-a">
  <p>The tab content.</p>
</article>

TabView content.

Show code 
<menu role="tablist" class="tabview" aria-label="Browser tabs">
  <button role="tab" aria-selected="true" aria-controls="tab-d">Home</button>
  <button role="tab" aria-controls="tab-e">Documents</button>
</menu>
<article role="tabpanel" id="tab-d">
  <p>TabView content.</p>
</article>

Theming

Dark mode

11.css follows the operating system's light or dark setting. To force a theme, set data-theme="light" or data-theme="dark" on <html> (or add .win11-dark / data-theme="dark" to any element to darken just that part of the page).

Dark window
Show code 
<div data-theme="dark" style="padding: 24px; border-radius: 8px; background: #202020">
  <div class="window" style="width: 300px">
    <div class="title-bar">
      <div class="title-bar-text">Dark window</div>
      <div class="title-bar-controls">
        <button aria-label="Minimize"></button>
        <button aria-label="Close"></button>
      </div>
    </div>
    <div class="window-body">
      <div class="field-row">
        <input type="checkbox" role="switch" id="dark-switch" checked />
        <label for="dark-switch">Dark mode</label>
      </div>
      <section class="field-row" style="justify-content: flex-end">
        <button class="default">OK</button>
        <button>Cancel</button>
      </section>
    </div>
  </div>
</div>

Design tokens

Every colour, radius and shadow is a --w11-* custom property defined in gui/_tokens.css. Override any of them to adjust the look.

Installation

From a CDN:

<link rel="stylesheet" href="https://unpkg.com/11.css" />

From npm:

npm install 11.css

import "11.css/dist/11.css";

Scoped

dist/11.scoped.css only styles elements inside a .win11 container, so it can live alongside other CSS. 

<link rel="stylesheet" href="https://unpkg.com/11.css/dist/11.scoped.css" />
<div class="win11">…</div>

Per component

Each component is also published on its own in dist/gui/. Import tokens.css and base.css first. 

import "11.css/dist/gui/tokens.css";
import "11.css/dist/gui/base.css";
import "11.css/dist/gui/button.css";
